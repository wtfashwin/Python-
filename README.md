# Python Practice Notebooks

A notebook collection for learning Python from basic syntax to object-oriented programming and data analysis.

## Topics

| Start here | Coverage |
| --- | --- |
| `Python_Basics.ipynb` | Python syntax and basic examples |
| `Comprehension.ipynb`, `Function.ipynb`, `Modules_.ipynb` | Comprehensions, functions, and modules |
| `OOPS_Basic_Concept.ipynb`, `Inheritance_in_OOPS.ipynb` | Classes, objects, and inheritance |
| `OOPS_Encapsulation.ipynb`, `Polymorphism_&_Abstraction.ipynb` | Encapsulation, polymorphism, and abstraction |
| `Pandas.ipynb`, `Data_Manipulation_&_Matplotlib.ipynb` | DataFrames, data manipulation, and plotting |
| `Assignments_1_4_.ipynb`, `Assignments_1_6_.ipynb` | Practice assignments |
| `Session_3.ipynb` | Additional session notes |

## How to use it

Open the notebooks in Jupyter or another notebook editor with a Python 3 kernel. Start with `Python_Basics.ipynb`, then choose a topic and run individual cells while changing the examples.

The data-analysis notebooks use pandas, NumPy, and Matplotlib. The repository does not pin these dependencies or define a shared environment. `Data_Manipulation_&_Matplotlib.ipynb` creates `sample_data.csv` in the current working directory as part of an example.

## Status and checks

Learning notes, examples, and exercises. Some saved cells show intentional error examples or interrupted runs. There is no automated test suite. Saved output does not establish that every notebook runs from top to bottom in a fresh environment.
